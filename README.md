# LeFlow project page

Project page for **LeFlow: Generative Latent Flow Planning for World Models**
([arXiv](https://arxiv.org/abs/2608.24855) · [code](https://github.com/hsiangwei0903/LeFlow)).

Live at https://hsiangwei0903.github.io/LeFlow-website/

Plain static HTML/CSS/JS, no build step. Preview locally with `python3 -m http.server` and open http://localhost:8000.
Page design adapted from the [WorldRecon](https://kszpxxzmc.github.io/WorldRecon-website/) project page.
